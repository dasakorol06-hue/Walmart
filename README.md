Данный проект представляет собой комплексный анализ данных о продажах сети супермаркетов Walmart. В рамках работы были проведены:

1. **Очистка и предобработка данных** — подготовка данных к анализу
2. **Исследовательский анализ (EDA)** — изучение структуры и закономерностей
3. **Анализ ключевых метрик** — выручка, средний чек, рейтинги
4. **Сегментация по категориям** — выявление лидеров по выручке
5. **Анализ времени покупок** — изучение паттернов активности
6. **Сравнительный анализ филиалов** — выявление лучших и проблемных точек

**Цель исследования:** выявить ключевые закономерности в продажах, определить точки роста для бизнеса и разработать практические рекомендации.

## Данные

**Источник:** Walmart Sales Dataset

**Описание данных:**
- **Период:** 2019–2023
- **Количество записей:** 10,020
- **Количество филиалов:** 100
- **Категории товаров:** 6

**Структура данных:**

| Колонка | Описание | Тип |
|---------|----------|-----|
| `invoice_id` | Уникальный номер чека | int |
| `Branch` | ID филиала | object |
| `City` | Город | object |
| `category` | Категория товара | object |
| `unit_price` | Цена за единицу ($) | float |
| `quantity` | Количество | int |
| `date` | Дата покупки | datetime |
| `time` | Время покупки | object |
| `payment_method` | Способ оплаты | object |
| `rating` | Рейтинг (1–10) | float |
